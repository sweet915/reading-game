# 📖 阅读小勇士：文字王国大冒险

面向小学生的语文阅读教育游戏。150篇分级阅读内容（中阶75篇三年级水平 + 高阶75篇五年级水平），五种互动玩法，含成长系统和家长中心。

## 部署到 GitHub Pages（3分钟）

1. 在 GitHub 新建一个仓库（Public），名字随意，比如 `reading-game`
2. 把本包里的所有文件上传到仓库根目录（可以直接网页拖拽上传）
3. 进入仓库的 **Settings → Pages**
4. Source 选择 **GitHub Actions**
5. 推送后等1-2分钟，Actions自动部署完成
6. 访问地址：`https://你的用户名.github.io/仓库名/`

## 更简单的方式（不用Actions）

如果嫌麻烦，也可以：
1. 上传文件后，Settings → Pages → Source 选 **Deploy from a branch**
2. Branch 选 `main`，目录选 `/ (root)`，保存
3. 等1分钟，访问同样的地址

## 手机/平板使用

- 直接访问部署后的网址即可，已做全设备适配
- 在 Safari（苹果）或 Chrome（安卓）里点"分享"→"添加到主屏幕"，就能像App一样全屏打开

## 家长中心

- 点击底部"家长中心"，默认密码 `8888`
- 可查看阅读时长、累计字数、汉字接触量、答题正确率、近7天统计
- 数据保存在设备本地（localStorage），不上传任何服务器
